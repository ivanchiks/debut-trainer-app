# Дебютный тренажёр

Открыть: **https://ivanchiks.github.io/debut-trainer-app/**

Тренажёр дебютов в одном файле: уроки, закрепление и интервальное повторение позиций. Работает в браузере компьютера и телефона, без регистрации. Прогресс хранится только в вашем браузере.

На телефоне: откройте ссылку → меню браузера → «Добавить на главный экран».

Импорт дебютов (PGN)

1. Файлы

Каждый файл станет курсом. Каждая партия в файле — главой.

2. Ссылка на студию Lichess

Работает только для открытых студий, где автор разрешил скачивание.

3. Вставить текст PGN

Боковой вариант на вашем ходу = «известная ошибка» с объяснением. Вариант на ходу соперника = другой ответ соперника. Сторона ученика — заголовок [Orientation "black"].
